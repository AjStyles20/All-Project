# Project 007 — Secure Coding Examination, Execution and Evidence-Based Integrity Platform

## Concept
A programming-examination environment with an integrated editor/execution workflow and configurable controls. It may preserve bounded evidence such as execution history, focus/tab events, clipboard events, and other integrity indicators for authorized human review.

## Current stage
RESEARCH FOUNDATION — strong candidate, but no implementation/novelty conclusion yet.

## Research mandate
Study computer-based assessment and programming-exam lineage, online judges, plagiarism/integrity systems, lockdown/proctoring approaches, coding IDE/execution sandboxes, AI-era assessment challenges, false positives, human adjudication, privacy, accessibility, security, sandboxing, academic policy, and current commercial/open-source systems.

## Boundary
The system must not infer “cheating” solely from a recorded event. Evidence collection, risk indicators, and authorized human judgment must remain distinguishable. Security claims require independent verification.
