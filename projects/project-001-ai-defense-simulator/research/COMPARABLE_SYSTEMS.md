# Comparable Systems Review

## Purpose
This document records a first-pass review of public products that overlap with Project 001. It is not an exhaustive market survey and must not be used to support absolute novelty claims.

## Systems Reviewed

### Microsoft PowerPoint Speaker Coach
Public Microsoft documentation shows that Speaker Coach evaluates delivery factors such as pace, pitch, filler words, wordiness, inclusiveness, originality/read-aloud behavior, and in some environments body language. It provides rehearsal feedback and a post-session report.

**Overlap with Project 001**
- presentation rehearsal
- speech/delivery analysis
- feedback after rehearsal

**Publicly documented distinction relevant to Project 001**
The reviewed documentation emphasizes delivery coaching rather than document-grounded viva/defense questioning, configurable examiner panels, or claim/evidence traceability.

### Yoodli
Public Yoodli documentation describes AI practice for presentations, pitches, interviews, and roleplays. Users can receive feedback and enter Q&A mode with AI-generated follow-up questions.

**Overlap with Project 001**
- presentation practice
- AI follow-up questions
- interview/roleplay scenarios
- microphone/camera-based practice
- post-session analysis

**Implication**
`AI presentation practice with AI follow-up questions` is not a defensible novelty claim for Project 001.

### VirtualSpeech
Public VirtualSpeech documentation describes browser/VR presentation practice, uploaded slides and notes, AI-generated questions, performance feedback, recordings, configurable distractions, virtual audiences, body-language/eye-contact analysis, interviews, roleplays, pitches, and other scenarios.

**Overlap with Project 001**
- uploaded presentation material
- AI-generated Q&A
- virtual audience simulation
- presentation/interview practice
- delivery feedback
- session recording/review
- configurable practice scenarios

**Implication**
A broad `virtual audience + slides + AI questions + feedback` product concept is already well represented in the market.

## Defensible Direction Emerging from Review
Project 001 should not compete on generic speech coaching or generic virtual-audience simulation alone.

The more defensible direction is a **source-grounded defense / viva / review simulator** focused on the content and reasoning behind the user's own work.

Candidate differentiators to investigate further:
- questions grounded in uploaded project/research documents, not only the spoken presentation
- explicit evidence/source traceability for generated questions and feedback
- multiple examiner/reviewer personas with distinct roles such as methodology, implementation, security, research-gap, product, or skeptical reviewer
- challenge questions derived from contradictions, unsupported claims, limitations, architecture decisions, and test evidence
- defense-readiness tracking across repeated sessions
- feedback separated into factual/content correctness, evidence quality, reasoning quality, delivery, and uncertainty
- direct support for technical project reviews, vivas, thesis defenses, architecture reviews, funding pitches, and professional design reviews

These are **candidate differentiators**, not yet verified novelty claims.

## Current Novelty Position
Do not claim that Project 001 is the first AI presentation coach, first AI Q&A simulator, first virtual audience system, first defense-practice system, or first RAG-enabled presentation tool.

A safer provisional position is:

> Reviewed presentation-coaching systems already provide speech analysis, virtual audiences, AI-generated questions, and presentation practice. Project 001 therefore focuses on a narrower problem: evidence-aware, source-grounded questioning and review of a user's own technical or research artifacts, with traceable feedback and configurable reviewer roles.

This statement remains UNDER REVIEW until the literature and product review are broader.
