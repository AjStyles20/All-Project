# Project 006 — Privacy-Aware Searchable Digital Activity and Screen Memory System

## Concept
A user-controlled system intended to help a person recover information they previously saw or worked with on a computer through selected screen/activity capture, chronological organization, extraction, segmentation, and search/retrieval.

## Current stage
RESEARCH FOUNDATION — privacy/security and platform feasibility are gating concerns.

## Research mandate
Investigate lifelogging and activity-history lineage, screenshot/OCR/activity indexing systems, semantic retrieval, current commercial and open-source recall products, operating-system facilities/restrictions, storage/retention/encryption, local-versus-cloud processing, consent, sensitive-content handling, performance, accessibility, attack surface, and deletion/export controls.

## Boundary
No continuous capture implementation before a privacy/security model and bounded retention/control design exist. Do not describe surveillance-like capabilities as benign merely because they are technically possible.
