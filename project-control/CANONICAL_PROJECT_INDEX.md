## P001 EGPCV vs P011 CDER internal novelty collision — 16 September 2026

The strict same-engine test fails for P011 as an independent research contribution.

P001 EGPCV already constructs bounded claims from provenance-bearing evidence, preserves gaps/contradictions/assistance dependence, triggers minimum targeted independent verification for unresolved claims, updates explicit evidence states, preserves human authority, and evaluates expert agreement plus verification burden. P011 CDER uses the same control loop over dissertation/project artifacts: claims → provenance-aware evidence → gap/contradiction analysis → verification-necessity decision → minimum targeted probe → evidence-state update → stop/abstain/human review.

A generalized evidence-gap verification engine can implement both by swapping domain adapters, claim ontologies, admissibility/policy rules, and probe libraries. The domain difference is meaningful for application/evaluation, but it is not enough to support two independent FYP novelty claims without a separately demonstrated mechanism-level distinction.

**Decision:** P011 is **PARKED as an independent FYP candidate**. CDER is retained as a dissertation/project-defense application/evaluation domain within the broader evidence-gap verification mechanism family established by P001 EGPCV. This is not a deletion of P011 documentation or provenance, and it does not authorize implementation or automatic scope expansion of P001.
