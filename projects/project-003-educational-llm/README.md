# Project 003 — Small Educational Language Model From First Principles

## Concept
Investigate the design, training, evaluation, and operation of a small language model from model foundations rather than simply wrapping an existing commercial LLM API. The educational objective includes tokenization, embeddings, attention, transformer blocks, training, inference, evaluation, compute limits, and failure modes.

## Current stage
RESEARCH / FEASIBILITY FOUNDATION — no implementation commitment yet.

## Research mandate
Trace relevant language-model and neural-network lineage as far back as evidence warrants; distinguish foundational work from modern transformer/LLM developments; inspect educational implementations and small-model projects; quantify realistic compute/data requirements on available hardware or affordable alternatives; establish what “from scratch” can defensibly mean; identify evaluation methodology, security/safety concerns, licensing/data issues, and a feasible learning contribution.

## Boundary
Do not imply frontier-model scale, capability, or training resources unless independently demonstrated.
