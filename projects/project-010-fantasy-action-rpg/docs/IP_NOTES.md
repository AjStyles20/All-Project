# IP notes for "Lanterns of Brinewold"

Pass 001 sets the boundary: the game may share only high-level qualities with the series that inspired the idea. It must not use that series' names, characters, places, story, dialogue, look or music.

## What the game takes (high-level qualities only)
- A squabbling but likeable party with distinct roles.
- Humour alongside real stakes.
- Banter between party members.
- An episodic quest that builds to a bigger threat.

These are common to the whole party-fantasy genre.

## What is original to this project
| Element | This game |
|---|---|
| World | Brinewold, a flooded borderland; the Lantern Road; the Grey Ferry; a drowned chapel |
| Threat | The Murk, a fog that raises drowned things and eats light |
| Party | Brannoch Vey (anchor-wielding dock fighter), Oswin Tallow (nervous lamplighter with firebombs), Ilse Marrow (hedge-healer who bargains with marsh spirits), Kettle (a clockwork heron) |
| Other characters | Dilly Pask, ferrywoman |
| Enemies | Drowned shamblers, Murk wisps, the Lantern-Eater |
| Story | Relight three waymarker lanterns to open the chapel and defeat what is eating the light |
| Dialogue | All lines in `game/src/data.js` were written for this project |
| Visuals and sound | Simple shapes drawn in code; no images, fonts or audio from anywhere else |

No name, character, place, line or visual element was taken from the inspiring series or from any other game. Before any public release, someone other than the author should still check for accidental similarity.
