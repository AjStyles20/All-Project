# Scope Parking Lot

Use this file for ideas that are useful or interesting but are not currently approved requirements.

## Decision Path
1. Is the idea required by an approved objective or requirement?
2. If not, does it materially improve the MVP or defense?
3. What is its cost, risk, dependency, and schedule impact?
4. If the benefit is not material now, park it rather than expanding scope.

## Statuses
- CANDIDATE
- REVIEW NEEDED
- APPROVED FOR CURRENT SCOPE
- POST-MVP
- FUTURE WORK
- REJECTED
