# P014 — Automated Log Analysis and Root-Cause Assistance Tool

## Class
GENERAL / PRODUCT SYSTEM

## Working problem
Parse heterogeneous logs, identify anomalous events, correlate evidence across time or components, and assist operators in identifying plausible root causes faster.

## Research before implementation
Research must cover log parsing, anomaly detection, temporal/event correlation, causal/root-cause analysis, observability/AIOps platforms, incident datasets, LLM-assisted diagnosis, explainability, false-positive risk, and evaluation against incidents with known ground truth.

## Current status
NOT STARTED — strong engineering/FYP candidate with expected crowded prior art.

## Guardrail
A fluent explanation is not evidence of correct root cause. The system must distinguish observed log evidence, correlations, hypotheses, and verified causes.
