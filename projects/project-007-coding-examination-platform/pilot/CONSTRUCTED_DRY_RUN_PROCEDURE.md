# P001 M8 Constructed Dry-Run Procedure — v1.0 Candidate

## Sequence

1. Freeze case bundle/version, assessor rubric, B2 contract, B4 catalogue/evaluator, and timing procedure.
2. Give Assessor A only the allowed case/evidence materials plus assessor worksheet.
3. Give Assessor B the same materials independently; do not reveal Assessor A's judgment.
4. Collect A/B state, rationale, ambiguity and additional-evidence fields before exposing method outputs.
5. Run/record the software comparison for the same frozen case/claim where the current bounded implementation supports it.
6. Record B0-B4 states, evidence IDs and raw burden. Do not invent B1 process evidence or missing time.
7. Compare assessor judgments with each other and with method outputs descriptively.
8. Log ambiguity/deviation. Do not silently reconcile disagreement.
9. Decide whether wording/rubric/probe/evaluator requires revision.
10. If materially revised, increment versions and repeat the affected dry run before M9.

## First dry-run subset

Start with CASE-PILOT-001 and CASE-PILOT-003. They test the two most important immediate questions: whether supplied-test correctness is kept separate from independent test-design competence, and whether PARTIAL versus UNRESOLVED is usable by independent assessors.

Do not claim that the dry run occurred until actual assessor worksheets/results exist.
