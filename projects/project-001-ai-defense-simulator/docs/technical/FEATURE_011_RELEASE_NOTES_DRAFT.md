# Feature 011 Release Notes Draft

Feature 011 turns the existing Project 001 capabilities into one coherent bounded rehearsal path. Users start a defense session and land directly on the first question, answer with text or the existing optional speech-input flow, review evidence-aware feedback, continue through evidence-grounded follow-ups, and finish with an explicit server-authoritative completed state.

The feature does not add accounts, public deployment, objective grading, or new provider privileges. Existing provenance, speech, provider, upload, CSP, same-origin, and workspace isolation controls remain release gates.
