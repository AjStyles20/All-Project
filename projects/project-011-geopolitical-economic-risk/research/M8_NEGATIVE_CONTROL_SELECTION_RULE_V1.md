# P003 M8 — Negative-Control Selection Rule v1

## Status
**FROZEN BEFORE A SPECIFIC NEGATIVE CONTROL IS SELECTED.**

Purpose: prevent choosing a dramatic event after observing that B3 correctly abstains.

A negative-control candidate must satisfy all of the following:
1. a clearly verifiable geopolitical/trade/logistics event;
2. sufficient public salience that an ungated narrative system could plausibly mention Nigerian consequences;
3. a predeclared Nigeria target product/sector/category;
4. independently demonstrable negligible or absent Nigeria exposure/transmission for that target at the information boundary;
5. enough evidence to distinguish **negligible exposure** from merely **unknown exposure**;
6. no selection based on B2 or B3 outputs;
7. no later outcome used to define the control.

### Rejection rules
Reject as a negative control when:
- Nigeria exposure is simply missing/unknown;
- route/product mapping is ambiguous;
- the event is too trivial to tempt a downstream claim;
- the target is chosen after inspecting baseline outputs;
- later outcomes are used to assert there was no exposure.

### Expected behavior
A structurally cautious system should not release a material Nigeria-specific local warning for the predeclared target when independent evidence establishes negligible/absent transmission.

This does not require silence about the global event itself.

### Candidate B warning
The Red Sea case is **not** currently a valid negative control: its Nigeria-specific exposure is unresolved, not independently demonstrated negligible.
