# P003 — B2 First-Wave Execution Readiness Gate

## Status
The first-wave B2 manifest is frozen and CI-verified. This checkpoint adds a final machine-enforced gate before any real model call.

## Gate
A B2 run can be prepared only when:
1. its run ID is uniquely present in `P003-B2-MANIFEST-v1`;
2. its packet ID matches the predeclared packet;
3. the current packet SHA-256 matches the hash frozen in the manifest;
4. the system prompt is the frozen v1 prompt;
5. the user prompt is generated deterministically from that packet.

Any post-manifest packet mutation therefore blocks execution rather than silently changing the experiment.

## First-wave scope
The only authorized run IDs are:
- B2-A-001
- B2-A-002
- B2-A-003
- B2-NC01-001
- B2-NC01-002
- B2-NC01-003

## Important boundary
This is readiness infrastructure, not model execution. No real B2 response has been generated by this checkpoint.

A real generation also requires an actual model/provider execution environment whose provider/model/version/timestamp/settings and raw response can be captured in `B2RunRecord`. Those details must not be fabricated.

## After a real call
For each valid generation:
prepare → call model → preserve raw response → create immutable B2RunRecord → hash record → extract atomic claims → blind baseline identity → independent review.

No empirical B2-vs-B3 conclusion is permitted before that chain is completed.
