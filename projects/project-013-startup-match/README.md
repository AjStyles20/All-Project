# P013 — StartupMatch: Founder–Investor Matching Platform

## Class
GENERAL / PRODUCT SYSTEM

## Working problem
Build a two-sided marketplace that connects startup founders with compatible investors using structured profiles, matching logic, secure communication, and transparent interaction.

## Research before implementation
Research must separate ordinary search/filtering from meaningful matching or recommendation, and examine founder-investor fit signals, cold start, ranking bias, marketplace incentives, fraud, identity verification, privacy, communications security, and existing startup/investor platforms.

## Current status
NOT STARTED — product-viable concept requiring prior-art and matching-method research.

## Guardrail
Compatibility scores must not be presented as objective investment-quality predictions unless the evidence supports that interpretation.
