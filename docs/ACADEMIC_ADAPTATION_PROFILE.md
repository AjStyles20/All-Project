# Academic Adaptation Profile

## Status
Optional. Not active by default.

## Purpose
This profile captures academic-document conventions that may be applied **after** AJ explicitly selects a project for academic submission. It is intentionally institution-neutral and contains no school name, supervisor name, staff name, student identifier, or institutional branding.

## Source Basis
A formal project-instruction document supplied by AJ was reviewed on 2026-09-08. Reusable academic structure and formatting requirements were extracted while excluding institution-specific identity and administrative pages from the default Project OS workflow.

## Academic Structure Available for Later Use
A selected project can be adapted into a five-part academic structure such as:

### Chapter 1 — Introduction
Typical sections:
- Overview
- Background and Motivation
- Statement of the Problem
- Aim and Objectives
- Significance of the Project
- Project Risk Assessment
- Scope / Project Organization

### Chapter 2 — Literature Review
Typical sections:
- Introduction
- Historical Overview
- Related Works
- Summary
- Literature summary / comparison table

### Chapter 3 — Requirements, Analysis, and Design
Typical sections:
- Overview
- Proposed Model
- Methodology
- Tools and Techniques
- Ethical Consideration
- Requirement Analysis
- Functional Requirements
- Non-Functional Requirements
- Application Architecture
- Use Case
- Data Design
- Activity Diagrams
- Data-flow Diagram
- Control-flow Diagram
- ERD where relevant
- User Interface Design

### Chapter 4 — Implementation and Testing
Typical sections:
- Overview
- Main Features
- Implementation Problems
- How Implementation Problems Were Resolved
- Testing
- Unit / Integration / System Test Plans
- Test Suite
- Test Traceability Matrix
- Test Report Summary
- Error Reports and Corrections
- User Guide
- Summary

### Chapter 5 — Discussion, Conclusion, and Recommendation
Typical sections:
- Overview
- Objective Assessment
- Limitations and Challenges
- Future Enhancements
- Recommendations
- Summary

Additional sections may include References and Appendices.

## Academic Formatting Options
When activated for a selected project, the source guideline can be used to produce an export with settings such as:
- A4 paper
- Times New Roman
- 12 pt main body
- 1.5 line spacing for the main body
- single spacing for the abstract and certain quoted/footnote material
- block paragraphing
- 3.5 cm left margin and 2.5 cm top/right/bottom margins
- chapter-based numbering for tables and figures
- figure captions below figures
- table captions above tables
- source attribution for non-original figures
- preliminary Roman-numeral pagination followed by Arabic page numbering for the main text

These are not Project OS defaults. They are applied only when AJ activates this academic profile.

## Abstract Profile
For an academic export, the source guideline specifies an abstract that:
- is no more than 250 words
- uses single spacing
- avoids first-person narration
- summarizes what was done, how it was done, findings/results, significance/conclusions
- is written only after the work is completed

## Literature Review Profile
The supplied academic guideline includes a minimum literature-review length and requires a detailed summary of reviewed literature in table form. When this profile is activated, confirm whether those requirements still apply to the selected project before enforcing them.

## References Profile
APA 7th Edition is the academic reference style captured from the supplied guideline. Project OS research records should preserve complete provenance so references can be converted cleanly to APA 7 later.

## Adaptation Rule
Academic output is derived from professional project truth:

`Project State + Research Evidence + Architecture + Implementation + Test Evidence + Limitations`

→ academic chapter structure and formatting

Never reverse this relationship. Do not alter technical reality merely to fit a dissertation template.

## Identity Rule
Do not populate:
- university/school name
- faculty/department name
- supervisor name
- staff/examiner names
- registration/student number
- signatures/certification wording

unless AJ explicitly asks for those fields when preparing a selected academic project.
